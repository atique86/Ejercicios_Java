# rrhh

Proyecto Java gestionado con Maven.

## Requisitos
- Java 17+ (o la version configurada en pom.xml)
- Maven 3.8+

## Ejecucion
`ash
mvn spring-boot:run
`

## Compilacion y pruebas
`ash
mvn clean test
mvn clean package
`

## Estructura
- src/main/java: codigo fuente
- src/main/resources: configuraciones y recursos
- src/test/java: pruebas
