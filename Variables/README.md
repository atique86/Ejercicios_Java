# Variables

Proyecto Java de practica (estructura simple con src).

## Requisitos
- Java 8+ o version compatible con tu IDE

## Ejecucion
1. Abre el proyecto en tu IDE (IntelliJ/NetBeans).
2. Ejecuta la clase principal (main).

## Compilacion por consola (opcional)
`ash
javac src/*.java
java -cp src NombreClasePrincipal
`

## Estructura
- src: codigo fuente
- out o uild: artefactos generados (si aplica)
